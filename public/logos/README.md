# Logos de empresas y modelos de IA

SVG originales de [@lobehub/icons-static-svg](https://github.com/lobehub/lobe-icons) v1.95.1 (licencia MIT del paquete),
con el tamaño fijado a 512 px para que se dibujen nítidos en canvas. El registro está en `public/js/engine/logos.js`.

Las marcas pertenecen a sus dueños. Uso editorial: identificar de qué empresa o modelo se habla en el vídeo,
sin insinuar patrocinio ni respaldo. Para añadir uno: descarga `<id>.svg` (o `<id>-color.svg`) del paquete,
guárdalo como `public/logos/<id>.svg`, cambia `width/height="1em"` por `512` y añádelo a `LOGOS`.
